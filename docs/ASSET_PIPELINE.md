# Asset Pipeline

Preferred sources: Poly Haven (CC0 assets) and Kenney (CC0 assets on relevant asset pages). Every external asset must have its exact source, author, license, and retrieval record before bundling. Mixed-license sources such as Sketchfab require individual review. Free audio is not automatically clinically valid; clinical breath sounds require SME/audio validation.

Pipeline: Search -> License check -> Download -> Metadata -> Optimization -> Technical QA -> Clinical/visual QA -> Integration.
