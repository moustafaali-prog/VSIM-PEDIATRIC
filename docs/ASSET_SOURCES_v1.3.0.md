# Asset Sources — v1.3.0

## Preferred CC0 source
Poly Haven states that its HDRIs, textures and 3D models are CC0. Source: https://polyhaven.com/license

The project may use Poly Haven environment materials after recording the exact asset identifier, source URL and checksum in the asset manifest.

## Runtime format
Three.js GLTFLoader supports glTF 2.0 and extensions including Draco, Meshopt and KTX2. Source: https://threejs.org/docs/pages/GLTFLoader.html

## Policy
- Never bundle an asset with unknown licensing.
- Record source, license, author when available, URL, local path and checksum.
- Clinical audio additionally requires clinical validation; a permissive copyright license does not make a sound clinically valid.
